A beautiful, interactive web application to generate and download professional business cards instantly. Build your personal brand in seconds with live preview and multiple themes!

## ✨ Features

- **Live Preview:** See your business card update in real-time as you type.
- **Multiple Themes:** Choose from Classic, Modern, and Dark themes to match your style.
- **High-Res Download:** Export your business card as a crisp, high-resolution PNG using `html2canvas`.
- **Print Ready:** Easily send your design directly to your printer with one click.
- **Responsive UI:** Glassmorphism design elements that look great on any screen.

## 🚀 Installation & Usage

1. **Clone the repository:**
   ```bash
   git clone https://github.com/RBKesh/business-card-generator.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd business-card-generator
   ```
3. **Run the app:**
   Simply open `index.html` in your favorite web browser. No server or build tools required!

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Libraries:** FontAwesome (icons), html2canvas (PNG export)
- **Fonts:** Inter (Google Fonts)
